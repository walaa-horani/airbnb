Payment Architecture Approaches

The biggest architectural decision: how deeply to integrate PayPal alongside Stripe Connect

A

Stripe Connect + PayPal Marketplace Recommended

Both payment providers run full marketplace flows with automatic host payouts and platform fee capture on both sides.

Guest pays
→
Platform holds
→
5% fee kept
→
95% to host
Works identically for Stripe and PayPal. Hosts register with Stripe Connect Express AND can receive PayPal payouts. Most professional — exactly how real Airbnb works.

Pros

  • Automatic payouts on both sides
  • Full lifecycle (hold → release or refund)
  • Platform fee always captured

Cons

  • PayPal Marketplace requires business approval
  • More integration complexity
B

Stripe Connect + PayPal Simple Simpler

Stripe Connect handles the full marketplace flow. PayPal is a basic payment button — platform manually handles fee split and host payout for PayPal bookings.

Stripe → auto split
|
PayPal → manual payout
PayPal payments land in your platform account. You manually transfer 95% to hosts later (or via a cron job). Hosts only need to register Stripe Connect — no PayPal account needed for hosts.

Pros

  • No PayPal Marketplace approval
  • Hosts only need Stripe onboarding
  • Faster to build

Cons

  • Manual PayPal host payouts
  • Platform holds guest money longer
C

Stripe Connect Only (PayPal Later) MVP First

Ship with Stripe Connect Express only. Add PayPal in a future phase once the core booking flow is stable.

Stripe Connect → full auto
→
PayPal → Phase 2
Reduces scope significantly. Many platforms launch without PayPal and add it later. You specified PayPal as a requirement, so only choose this if timeline is tight.

Pros

  • Fastest to launch
  • Full Stripe flow working day one

Cons

  • No PayPal for countries Stripe doesn't support
  • Defeats the stated requirement
